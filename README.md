# Kishan Bagh

किसान बाग — a farmer's garden.

`index.html` is a single-file home page with an interactive crop calendar for the three
Indian growing seasons (Rabi, Kharif, Zaid). Pick a month to see what is sown, growing
and harvested; filter by season. It opens on the current month, works in light and dark
mode, and needs no build step.

To publish it, turn on GitHub Pages for this branch (Settings → Pages → deploy from branch, root).

The crop timings follow the North Indian calendar. Edit the `MONTHS` table in the script
to match your own fields.
