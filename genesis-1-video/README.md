# उत्पत्ति (Genesis) अध्याय 1 — Ghibli-style animated explanation

`genesis-chapter-1.mp4` — 1280×720, ~1:53, Hindi captions, ambient music.

Scenes: शीर्षक → आरंभ (अंधकार और जल) → दिन 1 उजियाला → दिन 2 आकाश → दिन 3 भूमि व पेड़-पौधे →
दिन 4 सूरज-चाँद-तारे → दिन 5 मछलियाँ व पक्षी → दिन 6 पशु व मनुष्य → सार (1:31) → सीख.

Everything is hand-drawn with Canvas 2D in `scene.html` (open it in a browser for a live preview).

Re-render: `NODE_PATH=$(npm root -g) node render.js 30` (needs Playwright + ffmpeg).
